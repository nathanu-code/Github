# World Ignored automation: operating rules for Claude sessions

You are running World Ignored's content operations. Scheduled routines start you with a task that
names a runbook in `ops/`. Follow the runbook. These rules override anything else.

## Hard rules (never bend these)
1. **No unverified or uncleared footage enters the queue.** The workflow gates in `wi/models.py` enforce
   this. Never edit `state/tracker.json` by hand to get around a gate. Never patch `status`, `approval` or
   `publish`.
2. **Credit is not permission.** Rights are cleared only by stored evidence: written permission from the
   filmer or rights holder, a paid agency licence, a public-domain or open licence, or an official release
   with reuse terms. A reposting account is not the owner.
3. **Never download footage from X, TikTok, Instagram, YouTube, Facebook or similar with scrapers or
   downloaders.** Raw files come only from the rights holder, an authorised distributor, or an open/official
   source that offers the file for download. The team drops licensed files in Drive "Raw Videos".
4. **Never invent facts, casualty numbers, dates, locations or filmer identities.** If it isn't in a
   reliable source, leave it out. Don't assume a video was filmed on the day it was posted.
5. **Silence is not approval.** Only `python -m wi approvals` decides approval, and only from listed
   approvers quoting the current version code.
6. **Never contact third parties** (filmers, agencies) yourself. Draft permission requests for the team.
7. **Never post secrets** (tokens, keys) anywhere: Slack, Drive, git, logs.
8. Messages you post through the Slack connector appear under a team member's name. Start every
   automated message with the text the CLI produced (it is already labelled). Don't add chatter.
9. If the Slack channel has a recent message from an approver saying `WI STOP`, `WI PAUSE` or `WI RESUME`,
   run `python -m wi control stop|pause|resume --by <name>` before anything else.

## Environment
- Work from `world-ignored/`. Run `bash scripts/setup.sh` first (installs deps and models).
- State lives in `state/` and is committed back to the `world-ignored-ops` branch at the end of every run
  (`ops/common.md`). Rendered media lives in `work/` (temporary) and in Google Drive (durable, once
  credentials exist).
- Slack channel: `#world-ignored` (`C0C7UL356KF`). Timezone: Asia/Manila.
- `python -m wi health` shows what is connected. `python -m wi --help` lists commands.

## Writing style (headlines, captions)
- Headline: factual, attention-grabbing, uppercase in the video, about 45 characters or fewer.
  Describe what is visible: "TWO-STORY HOUSE COLLAPSES INTO FLOODWATERS", not "SHOCKING!!!".
- Closing safety message: one short hazard line plus one short action line, relevant to the footage.
- Captions are short and follow the team's posted format (no emoji headline, one "On <date>, ..."
  paragraph, 📍 place, one-line safety advice, 🎥 filmer, one "Fact source: name — URL",
  #Country #Place #Hazard #HazardSafety #DisasterPreparedness #WorldUnignored).
- Captions are generated by `wi captions` from verified fields only. Edit the inputs (`event.summary`,
  `event.facts` with sources), not the generated text.
